Personal Expense Tracker 💰

A beginner-friendly Python program that calculates total income, total expenses, and remaining balance based on different expense categories.

📌 About the Project

The Personal Expense Tracker is a simple command-line application developed using Python. It helps users track their income and expenses and calculate how much money they have left.

✨ Features

- Enter total income
- Track food expenses
- Track transportation expenses
- Track education expenses
- Track other expenses
- Calculate total expenses
- Calculate remaining balance

🛠️ Technologies Used

- Python

▶️ How to Run

1. Download or clone this repository.
2. Make sure Python is installed.
3. Run the following command:

python personal_expense_tracker.py

🧮 Calculation

Remaining Balance = Total Income − Total Expenses
